# Day 08 - Tailwind Image Carousel 

A simple and responsive **Image Carousel** created using **HTML and Tailwind CSS**.

This task demonstrates how to create multiple image slides with navigation dots using Tailwind CSS without JavaScript.

---

## 🚀 Technologies Used

- HTML5
- Tailwind CSS
- Responsive Design

---

## 📌 Features

- 🖼️ Multiple image slides
- 🎯 Navigation dots
- ✨ Smooth slide transition
- 🌄 Image overlay with titles
- 📱 Responsive layout
- 🎨 Tailwind CSS styling
- ⚡ No JavaScript required

---

## 🛠️ Concepts Used

- Tailwind CSS CDN
- `flex`
- `relative`
- `absolute`
- `overflow-hidden`
- `object-cover`
- `translate-x`
- `transition`
- `duration`
- `peer-checked`
- Responsive breakpoints
- Image overlays
