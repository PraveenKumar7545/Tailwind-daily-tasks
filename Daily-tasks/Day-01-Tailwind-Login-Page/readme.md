# Day 01 - Task 01 - Login Page
   
## 📌 Description
This is a simple beginner-level login page created using **HTML** and **Tailwind CSS**.

### Features
- Hero section with background image
- Text overlay on the hero image
- Simple login form
- Login button redirects to the hero section using an anchor (`href="#hero"`)
- Responsive layout using Tailwind CSS

## 🛠 Technologies Used
- HTML5
- Tailwind CSS
