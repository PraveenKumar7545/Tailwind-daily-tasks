# Day 03 - Tailwind SBI Fund Transfer Form

## 📌 Description

Created an SBI NEFT Fund Transfer Form using HTML5 and Tailwind CSS.

This project focuses on designing a clean and responsive banking form with tables, form controls, and utility classes provided by Tailwind CSS.

---

## 🛠️ Technologies Used

- HTML5
- Tailwind CSS

---

## 📚 Tailwind CSS Concepts Covered

- Utility Classes
- Responsive Layout
- Typography
- Background Colors
- Borders
- Border Radius
- Tables
- Form Styling
- Input Styling
- Button Styling
- Hover Effects
- Spacing (Margin & Padding)
- Shadow Effects
- Focus Ring

---

## ✨ Features

- SBI NEFT Transfer Form
- Account Selection Table
- Beneficiary Selection Table
- Amount Input Field
- Purpose Dropdown
- Payment Option Selection
- Responsive Form Layout
- Submit Button
- Cancel Button
- Clean Banking User Interface
