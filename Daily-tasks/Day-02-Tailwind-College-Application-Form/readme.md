# Day 02 - Tailwind College Application Form

## 📌 Description

Created a modern College Application Form using HTML5 and Tailwind CSS.

This project focuses on designing a clean, responsive, and user-friendly form using Tailwind CSS utility classes.

---

## 🛠️ Technologies Used

- HTML5
- Tailwind CSS

---

## 📚 Tailwind CSS Concepts Covered

- Utility Classes
- Responsive Layout
- Flexbox
- Typography
- Spacing (Margin & Padding)
- Background Colors
- Borders
- Border Radius
- Form Styling
- Button Styling
- Hover Effects
- Shadow Effects

---

## ✨ Features

- Student Registration Form
- Responsive Layout
- First & Last Name Fields
- Email and Password Fields
- Phone Number Input
- Gender Selection
- Skills Selection
- Department Dropdown
- Date Picker
- Time Picker
- Color Picker
- File Upload
- Register Button
- Reset Button
- Clean User Interface
