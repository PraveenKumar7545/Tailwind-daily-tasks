# Day 08 - Tailwind CSS Image Carousel

## 📌 Project Description

A responsive image carousel created using **HTML and Tailwind CSS**.

This project demonstrates how to create a simple image slider using Tailwind CSS utility classes and radio buttons without JavaScript.

## 🛠️ Technologies Used

- HTML5
- Tailwind CSS
- Responsive Design

## ✨ Features

- Responsive image carousel
- 3 different slides
- Navigation dots
- Smooth slide transition
- Hover effects
- Full-screen image presentation
- No JavaScript used
