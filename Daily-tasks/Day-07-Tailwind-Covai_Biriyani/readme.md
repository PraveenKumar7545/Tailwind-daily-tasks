# Day 07 - Tailwind Covai Biriyani 🍛

A responsive restaurant website created using **HTML5 and Tailwind CSS**.  
This project is designed as part of my daily Tailwind CSS practice to improve my understanding of utility-first styling and responsive web design.

## 🚀 Technologies Used

- HTML5
- Tailwind CSS
- Responsive Web Design
